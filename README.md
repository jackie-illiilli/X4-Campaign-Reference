## 先记住的结论

1. **新系列加入 AI 配音，需要重做对白时序。** 旧关大量使用固定 5–12 秒 delay；给它们直接加音频，容易抢话或截断。语音完成事件、对白中断、镜头结束应分开处理。
2. **可以在沙盒中追加弃船与任务。** Timelines 已有完整官方实现。独立场景里的全局禁用经济、锁派系关系、清场等逻辑不能整套移植过去。
3. **“飞行员列队听训”在原理上可实现。** 官方脚本支持房间内多个角色的明确坐标、朝向、注视目标和现有动画。推荐先在宽敞房间做静态列队，再扩展到停机坪；精确站军姿、整齐同步敬礼、自动口型效果仍需小场景验证。
4. **当前镜头只能按条件复用。** 已找到第六关 255 秒镜头与约 262 秒对白链不一致、第二关实际使用持续环绕、第三关高速旋转、第七关室内剧情仍拍站外等具体问题。详见 02。
5. **新系列可以按“主菜单直接选关”设计。** 协乐园采用普通独立gamestart、自有前端及原生结算宿主，当前流程已验收，无需进入Hub。项目不声明Timelines依赖；实际卸载DLC环境与原生scenario路线仍需分别验证。详见06、12。
6. **开场播片和大字幕不要求Timelines。** 基础游戏已有video cutscene与播放Lua；原生对白字幕由HUD的subchannelbar.lua绘制，自建选关菜单的fontsize不能直接修改它。详见07。

## 证据等级

全文使用以下区别，避免把“脚本里写了”误写成“已在游戏里验收”：

| 标记 | 意义 |
| --- | --- |
| 源码确认 | 本次能在实际 XML、XSD、catalog 索引中直接核对的行为或参数 |
| 历史实测记录 | 旧总结明确写过测试结果；本次没有重新进入游戏复测 |
| 用户验收 | 用户在对应版本实际游玩后确认目标流程可用；不扩展为所有异常分支均逐项通过 |
| 静态风险 | 源码结构或时间线暴露风险，画面故障与严重程度仍需游戏验证 |
| 新方案待验证 | 根据官方能力设计的下一步方案，尚未做成可运行原型 |

本次扩展内 123 个 XML 全部可解析；MD 与镜头分别通过所用 XSD；本地 `gatefall_*` 镜头 key 无缺失；中英文文本 ID 集合一致、无重复项。**这些检查不证明镜头好看、NPC 不穿模、配音可播放或任务能完整通关。**

复查命令，在游戏根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File '.\GatefallChronicles\战役制作参考\tools\audit_campaign.ps1'
```

该参数仅对本次 PowerShell 子进程有效。脚本读取扩展和本地 schema/catalog，只重写本目录 `证据` 下的两份报告；不更改系统执行策略或游戏数据。catalog 位置改变时须更新脚本。

## 下一系列建议先做的三个最小验证

按顺序完成，之后再写长篇剧情：

1. 两个角色各一句实录音频：室内正常音色、远程通讯音色、完整播放/打断/缺音频、中英文显示及暂停恢复。
2. 一间房内一名训话者与六名飞行员：稳定站位、镜头、对白退出、离开房间后恢复、保存读取。
3. 独立沙盒测试扩展：旧档首次启用只生成一艘弃船；认领后存取不再生成；完成一次任务只发一次奖励。

这三项是建议的后续原型，**本次尚未实现或游戏内测试**。
